# Special-Style

Website for the Moscow interior design studio [Special-Style](https://www.special-style.ru/), built from the Figma file *Special-Style — Website (Copy)*.

- Type: Jost and Cormorant (plus Cormorant SC / Cormorant Garamond)
- Pages: home, projects, in progress, journal, about, and four project stories
- Shared header: transparent over full-screen heroes, fading to beige (`#f0ebe5`) as you scroll
- Images exported from Figma at 3× for full-screen heroes and 2× for smaller frames where the export quota allowed

Open locally:

```bash
python3 -m http.server 8765
```

Then visit http://127.0.0.1:8765/
